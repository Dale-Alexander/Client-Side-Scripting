# Exercise 3
The starter inventory.ts intentionally has untyped parameters in the three core functions. Add Product[] and number parameter types, check the supplied return types, and implement the working logic. The Product interface and caller are supplied. The optional productNames function is already typed.

Before class: npm install
During class: npm run build
After a successful build: npm start
Class demonstration: npm run class-demo

For the three-error exercise, read errors-to-fix.ts. Create src/error-fixes.ts with the corrected code. The solution folder contains the finished answer.

The solution's dist folder is precompiled. Run npm start without installation to see the finished output. To edit and rebuild TypeScript you need npm install first. No global TypeScript installation is required.
