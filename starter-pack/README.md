# Starter pack

Contains two runnable recovery projects: product-mgmt and news-portal. Each has a basic App screen and no list component or answers.

Inside one project run `npm install`, then `npm start`. Open http://localhost:4200.

To practise project creation instead, follow the commands in the slides and do not run ng new inside an existing starter project. Each starter includes Bootstrap as a dependency, but its CSS import is deliberately left for you to add.

See STUDENT_TASKS.md, LECTURER_GUIDE.md and data/03-03-products.json.
